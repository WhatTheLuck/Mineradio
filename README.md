# Faveradio

> 把收藏、播放、歌词与实时视觉放进同一个 Windows 音乐空间。

![Faveradio 沉浸式播放界面](./docs/assets/readme/cinema-beat-smoke.png)

Faveradio 是一款面向 Windows 的桌面音乐播放器。它既可以播放本地音乐，也可以连接用户自己的音乐平台账号，并在播放过程中提供歌词舞台、3D 歌单架、音频响应视觉、摄像头手势、Smart Favorites 和 AI 选曲。

它不是简单的“播放器加频谱”：歌曲、歌词、封面、节奏、收藏标签和视觉参数被组织在同一个交互系统里。你可以只把它当作本地播放器，也可以逐步开启平台歌单、AI 推荐、Wallpaper Engine 或 EmoMusic 等高级能力。

> 项目对外名称现为 **Faveradio**。为兼容既有用户数据、更新链路和安装安全逻辑，当前 `2.3.4` 安装包文件名、进程名及部分内部字段仍沿用 `Mineradio`；这不会影响正常使用。

## 项目简介与社会价值

Faveradio 以音乐播放器为主体，尝试解决个人音乐收藏被分散在不同平台、不同歌单和不同推荐体系中的问题。项目可以连接网易云音乐、QQ 音乐、酷狗音乐等用户自有账号，读取权限范围内的歌单与收藏，并将多个来源合并、去重为统一歌单；Spotify 接入正在沟通开放接口，尚未作为当前版本的既有能力。AI 播放使用本地 MuQ-MuLan 编码音乐和文字标签，在当前歌单内按“必须符合 / 可以符合”条件选曲。

在用户明确授权摄像头后，EmoMusic 会将面部关键点、虹膜位置和视线方向抽象为粒子、网格或表面视觉；可选 VLM 进一步依据当前画面中可见的眼角、眼睑、嘴角和整体表情线索，输出紧张—放松、愤怒—平静、烦躁—闲适、悲伤—快乐、困倦—活力五个连续维度，并生成带权重的音乐风格建议。普通摄像头不能直接测量面部肌肉活动，也不能完成医学级“微表情识别”；这些结果只用于交互反馈和音乐语义探索。

项目的研究愿景，是把连续情绪向量、歌曲风格标签与用户主动反馈进一步连接起来：例如在用户呈现困倦相关外显状态时，提高“高能量”“明亮节奏”等标签的推荐权重，并持续观察后续趋势，由用户确认音乐是否真正有帮助。当前版本已经具备多平台收藏整合、歌曲标签分析、Face Mesh、五维可见情绪估计和音乐语义权重展示，但尚未把它们宣称为经过临床验证的自动治疗闭环，也不会自动判断某种情绪已经被“治愈”。

其社会意义主要体现在：

- **降低数字音乐割裂**：让用户以自己的收藏为中心组织音乐，而不是被单一平台的数据边界和推荐算法完全定义。
- **提升推荐透明度与自主权**：AI 标签可以查看、修改和约束，推荐范围被限制在用户选择的歌单内，减少不可解释的黑箱推送。
- **探索普惠的情绪觉察工具**：以非语言、低门槛的视听反馈帮助用户观察当下状态，为日常放松、注意调节、音乐表达和数字艺术体验提供新入口。
- **推动跨学科技术实践**：把音乐信息检索、情感计算、计算机视觉、实时音频分析、人机交互和隐私工程放在同一开源项目中，为教学、研究原型和创意技术开发提供可复用基础。
- **建立负责任的情感计算边界**：坚持授权开启、最小化采集、可随时关闭和不作医学诊断，避免把面部外观误当成一个人的真实心理、人格或健康结论。

## 主要能力

### 音乐与收藏

- 导入单曲或整个本地音乐文件夹，支持本地歌词与封面。
- 搜索和浏览网易云音乐、QQ 音乐、酷狗音乐、汽水音乐等来源。
- 使用用户自己的平台登录状态读取歌单、收藏及可用音源。
- 将多个平台歌单合并、去重并保存为普通的“合并收藏夹”。
- 支持顺序、循环、随机和 AI 播放，并保留真实的上一首播放历史。
- 提供每日推荐、继续播放、本地曲库和最近播放入口。

### Smart Favorites 与 AI 播放

- 为当前歌单分析风格、语言、情绪、年代和自定义语义标签。
- 标签支持“不选 / 必须符合 / 可以符合”三种状态。
- 可把歌曲封面或歌名拖到标签上，保存人工标注。
- AI 只在当前播放歌单中选曲，不会静默扩大推荐范围。
- MuQ 模型或歌曲音频不可用时会提示编码失败，普通播放不受影响。
- API Key 由 Electron 主进程通过 `safeStorage` 保存，不写入源码、渲染器或 `localStorage`。

### 沉浸式视觉

- 歌词舞台：主歌词、翻译、发光、景深、滚动和镜头联动。
- 3D 歌单架：在沉浸界面中浏览歌单和队列。
- 多套内置视觉预设，包括 Emily、星河、唱片、星球、滚筒、虚空、月蚀圣环、雨幕霓虹、折光蝶群和深海绽放。
- CyberRibbon：保留原始 Three.js 丝带、地形、星辰和后处理逻辑。
- SpaceVenom：保留原始 WebGL 2 磁流体、Starfield 和独立分频响应。
- EmoMusic：将 Face Mesh、视线、音乐 RMS、情绪向量、粒子、涟漪、射线和星河组合成实时视觉。
- 用户视觉存档支持保存、加载、JSON 导入导出和 MR2 短码分享。

### Windows 桌面能力

- 无边框桌面窗口、托盘和单实例运行。
- 完整桌面模式，将 Faveradio 场景放入 Windows 桌面层。
- 本地 Wallpaper Engine 项目识别、索引、静音运行和视觉参数控制。
- 自定义缓存目录、后台性能策略和低配置画质档位。

完整桌面模式、桌面图标层和 Wallpaper Engine Scene 运行属于 Windows 专用实验能力。首次使用前建议先保存工作，并确认显卡驱动和 Wallpaper Engine 状态正常。

## 生物医学音乐交互与研究定位

Faveradio 把音乐播放器进一步扩展为一个“身体信号—音频分析—视觉反馈”的实验平台。项目借鉴音乐认知神经科学、心理生理学、情感计算和生物反馈的研究方法，关注节奏、能量、注意、动作与主观感受如何在实时交互中相互影响。

这里的“音乐疗愈”指面向日常放松、注意调节、情绪觉察和创造性表达的技术探索，不等同于由合格治疗师实施的临床音乐治疗。现有研究表明，音乐知觉与听觉—运动网络、节拍预测和奖励加工有关，音乐干预也可能影响部分压力相关结果；但效果受到个体差异、情境、干预方式和研究设计影响，不能由一次摄像头推断或一段音乐直接推出医学结论。可参阅 [听觉—运动耦合综述](https://www.nature.com/articles/nrn2152)、[音乐期待与奖赏相关多巴胺释放研究](https://www.nature.com/articles/nn.2726) 和 [音乐治疗与压力的系统综述及 Meta 分析](https://pubmed.ncbi.nlm.nih.gov/33176590/)。

### 生理信号与未来研究接口

数字音乐生物反馈研究常使用心率和心搏间期、HRV、PPG、EDA/GSR、呼吸、皮肤温度、EMG 或 EEG 来描述自主神经、运动或脑电活动。Faveradio **当前没有采集或解释这些信号**，也不能从普通 RGB 摄像头反推出这些指标。相关方向可参考 [带生物传感的数字音乐干预综述](https://www.frontiersin.org/journals/computer-science/articles/10.3389/fcomp.2023.1165355/full)。

如果未来接入经过校准的可穿戴设备，建议保持以下研究边界：

- 使用个人静息基线和时间窗内变化，不用单一阈值给所有用户贴标签。
- 把生理信号、自我报告和行为数据视为不同证据源，保留置信度、缺失值和模态冲突。
- 采用知情同意、最小化采集、本地优先处理、可撤回和可删除的数据策略。
- 用预注册的重复测量、交叉实验或 N-of-1 设计评估效果，并明确区分相关性、即时体验和因果疗效。
- 涉及患者、诊断、治疗建议或高风险人群时，由伦理审查、临床专家和合格音乐治疗师共同设计与监督。

### 医疗与安全边界

Faveradio 不是医疗器械，不测量脑活动、心率、血氧、压力激素或自主神经状态，不提供诊断、治疗、危机干预或用药建议。Face Mesh、视线和 VLM 结果不能用于判断抑郁、焦虑、神经系统疾病、认知能力或真实意图，也不能替代 EEG、眼动仪、ECG/PPG 等专业设备。若存在持续情绪困扰、疼痛、睡眠问题或其他健康风险，请联系有资质的医疗或心理健康专业人员。

## 系统要求

- Windows 10 或 Windows 11，64 位。
- 建议使用支持 WebGL 2 的独立显卡或较新的核显。
- 本地音乐播放不需要平台账号或 LLM。
- 摄像头手势、Face Mesh 和 EmoMusic 需要可用摄像头。
- Wallpaper Engine 联动需要本机已安装相应软件及项目文件。
- AI 标签与云端 VLM 是可选功能，需要用户自行提供兼容服务和 API Key。

## 第一次使用

### 1. 进入播放器

启动动画结束后，点击画面或按 `Enter` 进入 Home。没有登录任何音乐平台也可以直接导入本地音乐。

### 2. 导入本地音乐

点击顶部的导入按钮，可选择：

- **单曲文件**：导入并立即播放。
- **多曲文件夹**：批量加入本地曲库和播放队列。
- **封面图片**：替换当前歌曲的显示封面。

本地曲库会保留可恢复的文件记录。FLAC 标签、内嵌封面、同步歌词和同名 `.lrc` 会在可用时读取。若移动或删除源音乐文件，需要重新导入对应位置。

### 3. 登录音乐平台

打开账号区域，选择需要使用的平台并按页面提示登录。Faveradio 只使用用户自己的账号状态，不提供绕过会员、付费或地区限制的能力。

不同平台的搜索、歌单、试听和完整播放权限可能不同。出现“能看到歌单但不能播放”时，优先检查当前平台的登录状态、会员权限和歌曲本身的可用性。

### 4. 开始播放

可从搜索、Home、平台歌单、本地曲库、合并收藏夹或 3D 歌单架启动播放。底部控制栏提供播放、上一首、下一首、播放模式、音量和 AI 模式。

播放器会根据当前歌曲加载歌词、封面和节奏信息。某项视觉分析失败不会中断基础音频播放。

## 合并收藏夹教程

合并收藏夹用于把多个来源的歌单整理为一个本地普通歌单。

1. 在 Home 打开 **合并收藏夹**。
2. 勾选需要合并的平台歌单或已有收藏夹。
3. 输入新收藏夹名称。
4. 点击 **建立合并收藏夹**。
5. 等待全部来源读取完成并去重。
6. 创建成功后可直接播放，也可以像普通收藏夹一样再次使用。

如果任一来源读取失败，界面会显示错误并允许重试，不会把缺少歌曲的不完整结果伪装为成功收藏夹。

## AI 播放教程

### 开启 AI 模式

1. 先播放任意歌单。
2. 点击底部播放栏的 **AI** 按钮。
3. 在播放栏上方输入当前想听的关键词，例如“夜晚”“女声”“器乐”“节奏强”。
4. 按 `Enter` 将关键词保存为标签。
5. 点击标签，在三种状态间循环：

   - **不选**：不影响推荐。
   - **必须符合**：硬性筛选条件。
   - **可以符合**：提高推荐权重，但不是硬性要求。

AI 下一首只会从当前歌单中选择。风格标签按原文编码，场景标签自动扩充为“适合在…时听的音乐”。开启多个“必须符合”条件后，如果没有歌曲满足条件，系统会如实提示。

### 人工标注

把标签拖到当前歌曲标题下方，可以保存人工标注。AI 选曲基于 MuQ 音频与文本向量相似度。

### MuQ 离线模型

Windows 安装包内包含 MuQ-MuLan 和所需骨干模型，无需配置 API Key。首次分析歌单时需等待音频采样与编码；完成后从本地向量缓存读取。

更多细节见 [合并收藏夹与 AI 播放](./docs/SMART_FAVORITES.md)。

## 视觉系统教程

### 打开视觉控制台

播放歌曲后打开视觉控制台。控制台按任务分为：

- **常用**：视觉预设和最常用参数。
- **界面**：背景、玻璃、颜色和窗口表现。
- **歌词**：字体、布局、清晰度、翻译和发光。
- **动效**：粒子、镜头、CyberRibbon、SpaceVenom 与 EmoMusic。
- **歌单架**：3D 歌单架的显示、镜头和内容。
- **系统**：性能、缓存、摄像头和桌面模式。

建议先选择整体预设，再调整细节。低配置设备可把画质切到“低”或“中”，关闭高质量歌词纹理、AI 景深和不需要的背景层。

### 保存视觉参数

在用户存档区域可以：

- 保存当前视觉状态。
- 重命名和加载存档。
- 导出或导入 JSON。
- 复制和粘贴 MR2 短码。

视觉存档保存的是参数，不包含音乐文件、账号凭据或 API Key。

### CyberRibbon 与 SpaceVenom

进入 **控制台 → 动效**：

- **赛博丝带**区域可选择原始预设、编辑参数、保存和加载。
- **星际磁流体**区域可选择 Venom/Blood/Bubble/Water 等预设并调整星空和音频响应。

两套视觉在独立 iframe 中运行，退出预设后会销毁对应渲染循环。自定义参数默认保存在程序目录下：

```text
visual-presets/cyber/*.json
visual-presets/space/*.json
```

如果安装目录不可写，保存会显示真实错误，不会静默保存到未知位置。更多说明见 [原项目视觉与参数保存](./docs/SOURCE_VISUALS.md)。

## EmoMusic 与摄像头

### 基础 Face Mesh

1. 在视觉预设中选择 **EmoMusic**。
2. 允许应用使用摄像头。
3. 选择粒子、网格或平面等面部显示模式。
4. 根据设备性能选择轻量、均衡或精细摄像头档位。
5. 正对摄像头并保持脸部光线均匀。

Face Mesh 和视线估算在本地处理。仅使用本地 Face Mesh 时，不会上传摄像头画面。检测不到人脸时，Faveradio 会停止情绪生成、丢弃进行中的结果并清除过期状态。

### 视线校准

1. 打开 **瞳孔与视线 · 轻量**。
2. 保持“识别瞳孔中心与视线”开启。
3. 正视屏幕中央。
4. 点击 **注视中央并校准**。
5. 按需开启双眼瞳孔标记和 RMS 射线。

普通 RGB 摄像头只能提供交互级视线估算，结果会受眼镜反光、光照、眨眼、头部角度和摄像头位置影响，不能替代专业眼动仪。

详见 [EmoMusic 瞳孔与视线识别](./docs/EMOMUSIC_EYE_TRACKING.md)。

### 可选云端 VLM

如果用户主动配置并开启云端 VLM 情绪分析，应用会通过 Electron 主进程把压缩后的当前画面或面部区域发送到用户配置的模型服务。API Key 不会进入渲染器，但图像数据会离开本机。使用前请阅读模型服务商的隐私政策，不需要该能力时保持关闭。

## 手势控制

在 **控制台 → 系统 → 摄像头交互** 中开启播放手势。当前界面提示的主要动作包括：

- 张掌：推开视觉元素。
- 捏合：旋转。
- 握拳：收束。
- 左右滑动：切歌。
- V 手势：播放或暂停。
- 食指：调节音量。
- 拇指：喜欢当前歌曲。
- 三指：控制歌词。

手势需要稳定保持后才执行，以降低误触。摄像头显示分辨率和模型推理质量是独立设置；提高画面分辨率不等于提高识别质量。

## Wallpaper Engine 与完整桌面模式

### 导入 Wallpaper Engine 项目

1. 打开 **控制台 → 界面 → Wallpaper Engine**。
2. 点击 **识别 / 导入**。
3. 选择自动识别本机库、导入目录，或导入单个项目/场景包。
4. 选择项目后调整透明度、位置和缩放。
5. 点击 **恢复原背景** 可退出当前壁纸。

Faveradio 只为项目建立本地索引，不会复制完整创意工坊目录。Video 项目由播放器直接播放；可用的 Scene 项目通过本机 Wallpaper Engine 运行。Scene 缓存只处理副本，原始项目不被修改。

### 完整桌面模式

完整桌面模式会把整个 Faveradio 界面放入 Windows 桌面层。进入后可通过控制台或配置的热键切换交互层和退出。若桌面图标、鼠标输入或窗口层级异常，先退出该模式，再从托盘完全关闭并重新启动应用。

## 数据、缓存与隐私

Faveradio 的用户数据可能包括：

- 平台登录状态。

## 性能建议

如果运行卡顿，可依次尝试：

1. 将画质档位改为“低”或“中”。
2. 使用默认 VSync，避免设置高于显示器刷新率的固定帧率。
3. 将歌词纹理清晰度降为 `1×` 或 `2×`。
4. 关闭高质量上下文歌词、AI 景深和不需要的背景层。
5. EmoMusic 摄像头使用“轻量”档位。
6. 暂停 Wallpaper Engine Scene、CyberRibbon 或 SpaceVenom 等高负载视觉。
7. 在本地缓存面板检查歌词、节奏图和壁纸缓存占用。

低配置优化原则见 [低配置优化说明](./docs/LOW_SPEC_OPTIMIZATION_DOCTRINE.md)。

## 常见问题

### 点击歌曲后没有声音

- 检查系统输出设备和 Faveradio 音量。
- 平台歌曲请确认账号仍处于登录状态，并具有对应歌曲的播放权限。
- 本地歌曲请确认原文件没有被移动或删除。
- 尝试下一首，确认问题是单曲音源还是全局音频输出。

### 平台歌单能读取，但某些歌曲不能播放

歌单读取权限和单曲播放权限并不相同。会员等级、地区、歌曲下架、试听限制或登录票据过期都可能造成这种情况。Faveradio 不会伪造完整音源权限。

### AI 标签一直显示分析中或超时

- 点击“单独测试响应”检查 Base URL、模型和 Key。
- 确认模型支持 OpenAI-compatible Chat Completions。
- 检查服务额度、响应速度和并发限制。
- 更换为响应稳定的指令模型后重试。
- 批量失败时应用会暂停后台队列，避免持续消耗额度。

### 摄像头没有画面

- 确认 Windows 已允许桌面应用使用摄像头。
- 关闭正在独占摄像头的会议或直播软件。
- 从“轻量”档位重新开启。
- 摄像头与真实 Face Mesh/视线效果必须在物理设备上验证，静态页面检查不能替代硬件测试。

### 开发模式运行后立即退出

应用使用单实例锁。若已安装版本正在运行，开发实例可能立即退出。请先从托盘彻底关闭已安装版本，再执行 `npm start`。

# MuQ-MuLan AI 播放

AI 播放默认开启，使用随安装包提供的本地 MuQ-MuLan 模型。首次播放歌单时，会从每首可播放歌曲约三分之一处取最多 10 秒，转为 24 kHz 单声道音频并编码；音频和标签向量缓存在用户数据目录的 `muq-embeddings.json`。风格标签按原文编码，场景标签编码为“适合在…时听的音乐”。“必须”会将候选限制在该标签在当前歌单相似度最高的一组歌曲中，“偏好”参与排序；推荐列表始终来自当前播放队列。切歌不等待编码；编码未完成且暂无推荐候选时按歌单顺序切换。歌单逐首显示已选标签的相关度百分比，未完成编码时显示“计算中”。无法读取完整音频的歌曲会跳过编码，并在播放器中提示编码失败。

Windows 打包前运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-muq-runtime.ps1`，在 `build/muq-placeholder-bundle/` 生成离线推理程序、FP16 MuQ-MuLan 主权重和骨干模型初始化占位文件。主权重加载时覆盖骨干参数；首次运行会在用户数据目录展开占位文件并缓存。打包脚本会检查这些文件，缺失时停止构建。MuQ 权重为 CC BY-NC 4.0；商业分发须另行获得授权。
