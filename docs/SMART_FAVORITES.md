# 合并收藏夹与 AI 播放

在 Home 打开“合并收藏夹”，多选已有的平台收藏夹或歌单，填写名称并创建。程序读取全部歌曲并去重，保存为普通收藏夹；读取失败会提示重试，不会创建缺少歌曲的结果。

播放任意歌单时，点击播放栏的“AI”按钮。播放栏上方可以输入关键词，回车保存为永久标签。点击标签在“不选 / 必须符合 / 可以符合”之间循环，可以同时选择多个标签。“必须符合”是硬条件，“可以符合”参与推荐权重。推荐范围是当前播放歌单。

把当前歌曲的封面或歌名拖到标签上即可保存人工标注。AI 下一首使用当前标签状态选择歌曲，上一首返回实际播放历史。分析进度和失败原因显示在标签栏，可点击重试。

## LLM 设置

在 AI 播放设置中填写服务地址、模型和 API Key。本次使用 `https://api.siliconflow.cn/v1` 与 `Qwen/Qwen3.5-4B`。Key 通过 Electron 主进程的 `safeStorage` 加密保存，不写入源码、页面存储或日志。

也可使用环境变量 `MINERADIO_LLM_API_KEY`、`MINERADIO_LLM_BASE_URL`、`MINERADIO_LLM_MODEL`，其优先级高于界面设置。浏览器预览没有桌面安全桥接，不支持保存 Key。

## 缓存与失败处理

程序尽量读取平台歌曲及专辑的风格、标签、语言和描述，再分批交给 LLM 分析，包括对自定义中文关键词的语义匹配。平台未提供的信息不会伪造成已读取的信息。

歌曲元数据、LLM 分析、人工标注、永久标签和播放历史保存在用户数据目录的 `smart-favorites.json`；该文件名是内部兼容名称。加密凭据保存在同目录的 `smart-favorites-llm.json`。新增关键词会触发对应语义分析，切换标签的三种状态会复用已有分析。普通合并收藏夹保存在内置收藏夹库。

LLM 不可用时仍可使用人工标注、平台标签及已有缓存；必须符合的条件不会被静默放宽。普通播放不受影响。跨平台歌曲能否播放仍取决于相应平台登录状态和歌曲可用性。

如果“单独测试响应”长期停在聊天接口或显示超时，说明 Key 和模型目录可能正常，但所选模型实例没有及时推理。请改用同一服务中响应稳定的指令模型后再点重试。批量分析会识别模型漏回的歌曲并自动拆小重试；单次请求失败会暂停后台队列，避免数千首歌持续重试和消耗额度。
