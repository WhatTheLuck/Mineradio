# 合并收藏夹与 MuQ AI 播放

合并收藏夹把多个来源的收藏歌曲去重后写入普通内置歌单。播放器默认开启 **AI** 模式，在当前播放队列中使用 MuQ-MuLan 推荐；播放栏的 **AI** 按钮可关闭或重新开启。

## 标签与推荐

新增标签时选择 **风格** 或 **场景**。风格标签按原文编码，例如“摇滚”“快乐”；场景标签自动扩充为“适合在开车时听的音乐”这样的句子。点击标签依次切换 **不选 → 尽量满足 → 必须满足**。所有被选标签会与歌曲音频向量计算余弦相似度；歌单每首歌分别显示已选标签的相关度百分比（余弦值乘以 100 并限制在 0%～100%，不是概率），尚无向量时显示“计算中”。“必须”将候选限制在当前歌单中该标签匹配度最高的约 35% 歌曲内，多个“必须”取交集；“尽量”参与排序。若交集为空，播放器明确提示。推荐列表显示候选歌曲，点击即可播放。

拖动标签到当前歌曲标题下方可以保留人工标注；人工标注不会代替 MuQ 相似度计算。上一首沿实际 AI 播放历史返回。

## 采样与缓存

对每首能获取完整音频的歌曲，从约三分之一处读取最多 10 秒，转换为 24 kHz 单声道 PCM，再交给软件内本地模型编码。音频和文字向量存储在用户数据目录的 `muq-embeddings.json`；歌曲 ID、时长或本地文件修订变化时重新编码。未拿到完整音频的歌曲会跳过。背景任务逐首处理；切歌直接使用已编码的推荐候选，编码尚未完成时立即按歌单顺序切换，后台继续编码。

AI 播放不调用 LLM，也不需要 API Key。普通播放不受模型编码失败影响。

## 打包

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-muq-runtime.ps1` 构建 Windows 离线推理程序。此步骤需要 Python 3.11，下载 MuQ-MuLan、MuQ 和 XLM-R 模型，并生成 `build/muq-placeholder-bundle/`。其中保留 FP16 MuQ-MuLan 主权重，骨干模型使用会被主权重覆盖的初始化占位文件。安装包把它放进 `resources/muq-runtime/`；首次运行时在用户数据目录展开占位文件，之后复用。目录缺失时构建会停止。MuQ 模型权重为 CC BY-NC 4.0，商业分发前须获得授权。
