# Mineradio 2.3.4

- 修复 MuQ 文本编码遇到无效 Unicode 字符时的 SentencePiece 类型转换异常。
- AI 推荐歌曲列表改用与播放器一致的样式，切歌保持即时响应，并展示标签相关度。
- 在预置标签旁直接添加风格或场景标签，输入最多 10 个字。
- MuQ 音频编码可暂停和继续；正在处理的歌曲完成后暂停，已编码向量与剩余队列保留，暂停状态跨重启保存。
- 英文界面切换状态可保存。

MuQ 模型权重采用 CC BY-NC 4.0；商业分发需另行取得授权。
