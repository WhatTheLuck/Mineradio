# Mineradio 2.3.3

- 本地歌曲缺少节奏缓存时自动运行 MR 分析，不再弹出节奏模式选择窗口。
- EmoMusic 可从下拉栏切换摄像头；人脸识别启动或连续推理失败时显示状态，并尝试恢复。
- MuQ 文本编码遇到临时 `TextEncodeInput` 异常时自动重试一次。
