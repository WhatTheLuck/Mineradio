# EmoMusic 瞳孔与视线识别

EmoMusic 复用现有 MediaPipe Face Mesh 的 478 点输出，从左右虹膜中心相对眼角、上下眼睑的位置估算视线方向。它不会启动第二个模型，也不会上传摄像头画面。

## 快速使用

1. 在视觉预设中选择 `EmoMusic`。
2. 打开“瞳孔与视线 · 轻量”。
3. 保持“识别瞳孔中心与视线”开启。
4. 正对摄像头、自然睁眼并注视屏幕中央，然后点击“注视中央并校准”。
5. 需要在画面中检查结果时，开启“显示双眼瞳孔标记”。画面不会在两眼中间绘制额外的方向线或靶标。

识别结果也会通过浏览器事件 `mineradio-gaze-update` 发出：

```js
window.addEventListener('mineradio-gaze-update', (event) => {
  console.log(event.detail);
  // { x, y, confidence, direction, pupilRatio }
});
```

`x`、`y` 的范围为 `-1..1`，方向以用户自身的左、右、上、下为准。`pupilRatio` 是虹膜轮廓相对眼宽的代理值，不是医学意义上的真实瞳孔直径。

## 低占用配置

- 轻量（默认）：640×480、24 FPS；Face Mesh 推理仍服从全局性能档位，适合常驻。
- 均衡：960×720、30 FPS；光线一般或人脸偏小时使用。
- 精细：1280×720、30 FPS；仅在设备余量充足时使用。
- 瞳孔中心与视线估算直接消费每一帧 Face Mesh 结果，二者帧率一致。计算只读取现成的虹膜圆心与眼睑点，不增加像素扫描或第二个模型。
- 稳定滤波：数值越小越稳定但跟随稍慢；默认 0.28。
- 中央死区：数值越大，中央注视越不容易因微小抖动切换方向；默认 0.12。

## 视线射线

- 两眼射线使用校准后的视线方向，不再使用面部法线。
- 射线只由 RMS 峰值包络触发；没有峰值时完全不绘制。
- 射线亮度、宽度和长度随峰值强度闪现并快速衰减。
- “射线粗细”的最大值为 8.0。

## 使用边界

这是普通 RGB 前置摄像头上的交互级估算，适合视觉反馈、轻量交互和原型验证。结果会受光照、眼镜反光、眨眼、头部大角度偏转和摄像头位置影响，不能替代带红外照明、专用近眼相机和多点标定的研究级眼动仪。
